# MNIST Handwritten Digit Classification

A Computer Vision and Neural Network classification project built with Python and Scikit-learn that recognizes handwritten digits (`0` through `9`) from grayscale image pixel arrays.

## Tech Stack
- **Language:** Python 3
- **Libraries:** NumPy, Scikit-learn (`MLPClassifier`, `StandardScaler`)

## Key Features
- Image pixel normalization using `StandardScaler`
- Multi-Layer Perceptron (Neural Network) trained on handwritten digit matrices
- Detailed precision, recall, and F1-score evaluation across all 10 digit classes (96%+ accuracy)
